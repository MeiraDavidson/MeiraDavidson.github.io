Finding the global extremum on a closed interval

Often the domain is a closed interval [a,b][a,b] — a quantity that can’t go below aa or above bb. Here the Extreme Value Theorem from Chapter 2 makes a flat guarantee: a continuous function on a closed interval does attain a global maximum and a global minimum somewhere on it. They exist; we just have to find them. And the candidate list is finite:

Closed-interval method. To find the global max and min of a continuous ff on [a,b][a,b]: 1. Find all critical points inside (a,b)(a,b). 2. Evaluate ff at each critical point and at both endpoints aa and bb. 3. The largest value is the global max; the smallest is the global min.

The endpoints earn their place because Fermat’s theorem only governs interior extrema — on a closed interval, the highest point can sit at an edge where the slope never had to be zero. (Figure 8.5: a curve on [a,b][a,b] whose global maximum is at an interior critical point but whose global minimum is at an endpoint, showing why both must be checked.)

Worked example. Find the global extremes of f(x)=x3−3xf(x) = x^3 - 3x on [0,2][0, 2]. Critical points: f′(x)=3x2−3=0⇒x=±1f'(x) = 3x^2 - 3 = 0 \Rightarrow x = \pm 1, of which only x=1x = 1 is in (0,2)(0,2). Evaluate at the candidates {0,1,2}\{0, 1, 2\}: f(0)=0f(0) = 0, f(1)=−2f(1) = -2, f(2)=2f(2) = 2. So the global minimum is −2-2 at x=1x = 1, and the global maximum is 22 at the endpoint x=2x = 2. (Notice the max hid at an endpoint — exactly the case the method is built to catch.)

Optimization in the wild: a worked design problem

The real payoff is turning a word problem into a function and minimizing it. Here is the genre’s classic, an honest engineering question.

Problem. A cylindrical can must hold a fixed volume VV. What dimensions use the least metal (least surface area)?

Set it up. A cylinder of radius rr and height hh has surface area S=2πr2+2πrhS = 2\pi r^2 + 2\pi r h (two circular ends plus the wall) and volume V=πr2hV = \pi r^2 h. We want to minimize SS, but it has two variables — so use the volume constraint to eliminate one. From V=πr2hV = \pi r^2 h, h=Vπr2\;h = \dfrac{V}{\pi r^2}, and substituting:

S(r)=2πr2+2πr⋅Vπr2=2πr2+2Vr.S(r) = 2\pi r^2 + 2\pi r\cdot\frac{V}{\pi r^2} = 2\pi r^2 + \frac{2V}{r}.

Optimize. Set S′(r)=0S'(r) = 0: S′(r)=4πr−2Vr2=0⇒4πr=2Vr2⇒r3=V2π\; S'(r) = 4\pi r - \dfrac{2V}{r^2} = 0 \Rightarrow 4\pi r = \dfrac{2V}{r^2} \Rightarrow r^3 = \dfrac{V}{2\pi}. Confirm it’s a minimum (not a max): S″(r)=4π+4Vr3>0S''(r) = 4\pi + \dfrac{4V}{r^3} > 0 for all r>0r > 0 — so SS is convex, and by our theorem this lone critical point is the global minimum. No further checking needed; convexity guarantees it.

Read the answer. With r3=V2πr^3 = \tfrac{V}{2\pi}, the height works out to h=Vπr2=2rh = \dfrac{V}{\pi r^2} = 2r. The most efficient can is exactly as tall as it is wide (h=2rh = 2r, height equals diameter). That’s a clean, memorable design law — and the reason real cans aren’t shaped that way is that they optimize for shelf appearance and grip, not metal, which is its own lesson about what “optimal” means once you choose the right thing to minimize.
