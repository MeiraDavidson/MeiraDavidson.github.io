Logarithms: undoing the exponential

We have a function that grows. We will constantly need to run it backward: “the account reached $5000 — how long did that take?” Running exe^x backward is exactly what the natural logarithm ln\ln does. In the language of Chapter 4, ln\ln is the inverse function of exe^x:

y=ex⇔x=ln⁡y.y = e^{x} \quad\Longleftrightarrow\quad x = \ln y.

ln\ln takes in “what the exponential grew to” and gives back “the input that got us there.” Two facts fall straight out of being an inverse: ln⁡(ex)=x\ln(e^x) = x and eln⁡y=ye^{\ln y} = y. And the exponent rules become logarithm rules — for instance, since exey=ex+ye^{x}e^{y} = e^{x+y}, taking ln\ln of both sides turns multiplication into addition:

ln⁡(AB)=ln⁡A+ln⁡B.\ln(AB) = \ln A + \ln B.

(That single property — turns multiplication into addition — is the entire reason logarithms were invented, centuries before anyone cared about calculus. It is also why log scales work, which we will get to.)

Now the part worth the price of admission: what is the derivative of ln⁡x\ln x? We do not need a new limit. We have a tool for differentiating inverse functions from Chapter 4, and this is its finest hour. Let y=ln⁡xy = \ln x. By the definition of ln\ln, that means

ey=x.e^{y} = x.

Differentiate both sides with respect to xx. The right side is easy: ddxx=1\frac{d}{dx}x = 1. The left side needs the chain rule, because yy is itself a function of xx:

ey⋅dydx=1.e^{y}\cdot\frac{dy}{dx} = 1.

Solve for dydx\frac{dy}{dx}, then use ey=xe^y = x:

dydx=1ey=1x.\frac{dy}{dx} = \frac{1}{e^{y}} = \frac{1}{x}.

ddxln⁡x=1x\boxed{\;\frac{d}{dx}\,\ln x = \frac{1}{x}\;}

Take a moment with how clean that was. We never computed a single difference quotient for ln\ln. We leaned entirely on “ln\ln is the inverse of exe^x” plus the chain rule, and the answer dropped out in three lines. This is what it feels like when the earlier tools start paying for themselves.

Paying off one small debt right now: the mystery constant was ln⁡a\ln a

I promised that the mysterious M(a)M(a) — the slope of axa^x at the axis — is really ln⁡a\ln a. We can settle that one immediately, because we now have the machine to do it. The trick is to write every exponential in terms of the one base we understand. Since a=eln⁡aa = e^{\ln a},

ax=(eln⁡a)x=e(ln⁡a)x.a^{x} = \left(e^{\ln a}\right)^{x} = e^{(\ln a)\,x}.

Now differentiate using the chain-rule line from the toolkit, with k=ln⁡ak = \ln a:

ddxax=ddxe(ln⁡a)x=(ln⁡a)e(ln⁡a)x=(ln⁡a)ax.\frac{d}{dx}a^{x} = \frac{d}{dx}e^{(\ln a)x} = (\ln a)\,e^{(\ln a)x} = (\ln a)\,a^{x}.

So M(a)=ln⁡aM(a) = \ln a, exactly as advertised. The “mystery number” attached to every base was never mysterious; it was the natural log of the base all along. And notice the consistency check: M(e)=ln⁡e=1M(e) = \ln e = 1, which is precisely the condition we used to define ee. Everything closes up.
