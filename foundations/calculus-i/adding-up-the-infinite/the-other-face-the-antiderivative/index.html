Calculus I · Adding Up the Infinite

The other face: the antiderivative

Now set area aside entirely and ask a question that sounds unrelated. Differentiation turns FF into F′F'. Can we run it backward — given a function ff, find a function FF whose derivative is ff? Such an FF is called an antiderivative of ff.

For example, an antiderivative of 2x2x is x2x^2, because ddxx2=2x\tfrac{d}{dx}x^2 = 2x. But so is x2+1x^2 + 1, and x2−7x^2 - 7 — adding any constant leaves the derivative unchanged. This is not sloppiness; it is the whole truth, and Chapter 6 already proved it: if two functions have the same derivative, they differ by a constant (because F′=G′F' = G' means (F−G)′=0(F-G)' = 0, and a function with zero derivative everywhere is constant — a consequence of the Mean Value Theorem). So antiderivatives come in families, all parallel, separated by a constant:

The indefinite integral. ∫f(x)dx=F(x)+C\displaystyle\int f(x)\,dx = F(x) + C, where F′=fF' = f and CC is an arbitrary constant — the whole family of antiderivatives at once.

(Notice the same symbol ∫\int now appears without limits aa and bb. That collision of notation is a deliberate hint: the area problem and the antiderivative problem are about to turn out to be the same problem. For now, treat them as separate — definite integral with limits is a number, indefinite integral without limits is a family of functions.)

The standard antiderivative library

Finding antiderivatives is just running the Chapter 4 rules backward. Every derivative you learned becomes an antiderivative read right to left:

  • Power rule, reversed: ∫xndx=xn+1n+1+C\displaystyle\int x^n\,dx = \frac{x^{n+1}}{n+1} + C (for n≠−1n \ne -1). Check by differentiating the answer. (Raise the power by one and divide by the new power — the opposite of “drop the power and subtract one.”)
  • The exception, n=−1n = -1: ∫1xdx=ln⁡|x|+C\displaystyle\int \frac1x\,dx = \ln|x| + C. The power rule would divide by zero here, so this one stands apart — and it is no accident, as Chapter 11’s capstone will reveal.
  • Exponential: ∫exdx=ex+C\displaystyle\int e^x\,dx = e^x + C (it is its own antiderivative, just as it’s its own derivative).
  • Trigonometric — now within reach, because Chapter 4 derived the matching derivatives: since ddxsin⁡x=cos⁡x\tfrac{d}{dx}\sin x = \cos x, ∫cos⁡xdx=sin⁡x+C,∫sin⁡xdx=−cos⁡x+C,∫sec⁡2xdx=tan⁡x+C.\int \cos x\,dx = \sin x + C, \qquad \int \sin x\,dx = -\cos x + C, \qquad \int \sec^2 x\,dx = \tan x + C. (Mind the minus sign on ∫sin\int\sin: the antiderivative of sine is negative cosine, because the derivative of cosine carries the minus.)
  • Linearity, as for definite integrals: antiderivative of a sum is the sum of antiderivatives, and constants pull out.

So ∫(3x2−4cos⁡x+ex)dx=x3−4sin⁡x+ex+C\displaystyle\int (3x^2 - 4\cos x + e^x)\,dx = x^3 - 4\sin x + e^x + C — reverse each term, attach one CC at the end. Differentiate it back to check, and you recover the integrand exactly.
