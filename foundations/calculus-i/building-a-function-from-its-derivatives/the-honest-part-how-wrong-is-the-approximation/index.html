The honest part: how wrong is the approximation?

A Taylor polynomial is an approximation, and an approximation you can’t bound is a guess. So we account for the gap exactly. Write

f(x)=Tn(x)+Rn(x),f(x) = T_n(x) + R_n(x),

where Rn(x)R_n(x) is the remainder — everything the polynomial missed. Taylor’s theorem gives it a stunningly clean form:

Taylor’s Theorem (Lagrange remainder). For some point cc between aa and xx, Rn(x)=f(n+1)(c)(n+1)!(x−a)n+1.R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}.

Stare at that. It is exactly the next term of the series — the (n+1)(n+1)-th — except the derivative is evaluated not at the center aa but at some unknown point cc in between. And now look at the smallest case, n=0n = 0:

f(x)=f(a)+f′(c)(x−a).f(x) = f(a) + f'(c)(x - a).

That is the Mean Value Theorem. The n=1n=1 case is f(x)=f(a)+f′(a)(x−a)+12f″(c)(x−a)2f(x) = f(a) + f'(a)(x-a) + \tfrac12 f''(c)(x-a)^2 — the “second-order MVT” we previewed in Chapter 6. Taylor’s remainder is the Mean Value Theorem, escalated one derivative at a time. This is precisely why we proved the MVT — and its Cauchy cousin — before we got here: they are the engine that produces this error term.

The unknown cc might look like it ruins everything — how can a formula with a mystery point be useful? Because you don’t need to find cc; you only need to bound f(n+1)f^{(n+1)} over the interval. If |f(n+1)|≤M|f^{(n+1)}| \le M between aa and xx, then

|Rn(x)|≤M|x−a|n+1(n+1)!.|R_n(x)| \le \frac{M\,|x-a|^{n+1}}{(n+1)!}.

Worked example — e0.1e^{0.1} with a guarantee. Take f=exf = e^x, a=0a = 0, n=2n = 2, so T2(0.1)=1+0.1+0.012=1.105T_2(0.1) = 1 + 0.1 + \tfrac{0.01}{2} = 1.105. The remainder needs f‴=exf''' = e^x, and on [0,0.1][0, 0.1] we have ex≤e0.1<1.2e^x \le e^{0.1} < 1.2. So

|R2(0.1)|≤1.2⋅(0.1)33!=1.2×0.0016=0.0002.|R_2(0.1)| \le \frac{1.2 \cdot (0.1)^3}{3!} = \frac{1.2 \times 0.001}{6} = 0.0002.

We have proven, without a calculator, that 1.1051.105 is within 0.00020.0002 of the true e0.1e^{0.1}. (It is: the true value is 1.105171.10517, off by 0.000170.00017.) That is the difference between Taylor as a suggestion and Taylor as mathematics: the remainder turns “approximately” into a number you can stand behind.

◆ Layer 2 — Proof of Taylor’s theorem with Lagrange remainder

Fix the target xx. Choose the number MM that makes the equation exact: f(x)=Tn(x)+M(x−a)n+1f(x) = T_n(x) + M(x-a)^{n+1}. We’ll show M=f(n+1)(c)(n+1)!M = \tfrac{f^{(n+1)}(c)}{(n+1)!} for some cc. Define, as a function of a moving center tt, g(t)=f(x)−∑k=0nf(k)(t)k!(x−t)k−M(x−t)n+1.g(t) = f(x) - \sum_{k=0}^{n}\frac{f^{(k)}(t)}{k!}(x-t)^k - M(x-t)^{n+1}. Two endpoint checks: g(x)=f(x)−f(x)−0=0g(x) = f(x) - f(x) - 0 = 0 (only the k=0k=0 term of the sum survives at t=xt=x, giving f(x)f(x)), and g(a)=0g(a) = 0 by our choice of MM. So g(a)=g(x)g(a) = g(x), and Rolle’s theorem (Chapter 6) gives a cc with g′(c)=0g'(c) = 0. Now differentiate gg. The sum telescopes — each term’s product-rule pieces cancel against the next term’s — leaving only ddt∑k=0nf(k)(t)k!(x−t)k=f(n+1)(t)n!(x−t)n.\frac{d}{dt}\sum_{k=0}^n \frac{f^{(k)}(t)}{k!}(x-t)^k = \frac{f^{(n+1)}(t)}{n!}(x-t)^n. So g′(t)=−f(n+1)(t)n!(x−t)n+M(n+1)(x−t)ng'(t) = -\tfrac{f^{(n+1)}(t)}{n!}(x-t)^n + M(n+1)(x-t)^n. Setting g′(c)=0g'(c) = 0 and canceling (x−c)n(x-c)^n: M(n+1)=f(n+1)(c)n!⇒M=f(n+1)(c)(n+1)!.◼M(n+1) = \frac{f^{(n+1)}(c)}{n!} \qquad\Longrightarrow\qquad M = \frac{f^{(n+1)}(c)}{(n+1)!}. \qquad\blacksquare One auxiliary function, one application of Rolle — the same tilt-and-flatten move that gave us the MVT itself, run at higher order.

◆ Layer 2 — Why exe^x actually equals its series everywhere

Having a series isn’t the same as the series being true. For exe^x it is, for every xx, and the remainder proves it. With a=0a=0, |Rn(x)|=ec|x|n+1(n+1)!|R_n(x)| = \tfrac{e^c\,|x|^{n+1}}{(n+1)!} for some cc between 00 and xx, so |Rn(x)|≤e|x||x|n+1(n+1)!|R_n(x)| \le \tfrac{e^{|x|}\,|x|^{n+1}}{(n+1)!}. Fix xx and let n→∞n\to\infty: the factorial in the denominator overwhelms the power in the numerator (you saw in Chapter 1 how violently n!n! outgrows any fixed base raised to nn), so Rn(x)→0R_n(x)\to 0. The polynomials converge to exe^x itself. That is what licenses writing “==” instead of “≈\approx.”
