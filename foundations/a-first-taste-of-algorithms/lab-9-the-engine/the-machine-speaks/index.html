7. A real attention head

The pieces, dimensioned (D = model dimension, V = vocabulary, BLOCK = longest sequence):

BLOCK = 16 D = 32; Dk = 32 Wtok = rng.standard_normal((V, D)) * 0.1 # character -> vector Wpos = rng.standard_normal((BLOCK, D)) * 0.1 # position -> vector WQ = rng.standard_normal((D, Dk)) * 0.1 # query projection WK = rng.standard_normal((D, Dk)) * 0.1 # key projection WV = rng.standard_normal((D, D)) * 0.1 # value projection Wout = rng.standard_normal((D, V)) * 0.1 # context -> next-char scores

def softmax_rows(M): M = M - M.max(axis=-1, keepdims=True) e = np.exp(M) return e / e.sum(axis=-1, keepdims=True)


The forward pass *is* the five equations, in order — embed, project to Q/K/V, score, mask, weight, combine, read out:

```python
def forward(seq):
    T = len(seq)
    X = Wtok[seq] + Wpos[:T]                  # (T,D)  symbols + positions
    Q = X @ WQ; K = X @ WK; Vv = X @ WV       # the three projections
    scores = Q @ K.T / np.sqrt(Dk)            # (T,T)  query · key, scaled
    mask = np.triu(np.ones((T, T)), k=1).astype(bool)
    scores = np.where(mask, -1e9, scores)     # causal: no peeking ahead
    A = softmax_rows(scores)                  # (T,T)  attention weights
    context = A @ Vv                          # (T,D)  weighted values
    logits = context @ Wout                   # (T,V)  next-char scores
    return logits, A

seq = [stoi[c] for c in "." + "riemann"]

print("attention matrix shape:", A.shape, " (should be square, one row per position)")
