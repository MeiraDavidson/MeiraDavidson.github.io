3.7 The trick that tells you ``yes, this is a function''

Remember the one unbreakable law? Same input, same output — one input can never give two different outputs. On a graph, the horizontal direction is the input and the vertical is the output. So “one input gives two different outputs” would look like a single spot on the horizontal axis having two dots stacked above it. Which gives us a dead-simple test: The vertical line test. Sweep a vertical line across the graph. If it ever touches the graph in two places at once, it’s not a function — that single input is trying to produce two outputs.

The vertical line test is just the “same input, same output” law seen sideways. The parabola passes (every vertical line hits once); the sideways parabola fails (a vertical line hits twice).

It isn’t a separate rule to memorize. It’s the “same input, same output” law seen sideways. That’s the payoff of understanding why the law exists — the test stops being mysterious and becomes something you could have invented yourself.

3.8 Chaining machines together (composition)

Here’s where functions start to feel powerful. What if you took the output of one machine and fed it straight into another? Bolt the spout of the first onto the funnel of the second. Now you’ve built a bigger machine out of two smaller ones. Say machine one adds 1: g(x) = x + 1. And machine two squares: f(x) = x2. Drop in 3. The first machine makes it 4. The second squares that into 16. We write this chaining as f(g(x)) — read “f of g of x” — and you read it from the inside out, just like the order the number actually travels. This is called composition, and it is, quietly, one of the biggest ideas you’ll ever meet. Why so big? Because everything complicated is made of simple things chained together. A long, intimidating formula is almost always just a handful of tiny, boring machines bolted end to end.
